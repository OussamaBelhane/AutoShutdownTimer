# Auto Shutdown Timer

A sleek, lightweight desktop utility for Windows to schedule automatic power actions (Shutdown, Force Shutdown, Restart, Sleep).

## Features
- Ultra-low CPU & RAM consumption
- Dark theme interface
- Custom duration selector (Hours, Minutes, Seconds)
- Quick presets (30m, 1h, 2h, 4h, 8h, 12h)
- Force close running applications toggle
- Instant cancellation / abort
- System tray minimization with live countdown in tray tooltip

## Running from Source
```bash
pip install -r requirements.txt
python app.py
```

## Build Executable
```bash
python build.py
```
Executable will be generated in the `dist/` directory.
